# dctl-reels-media

DCTL Lab（[@dctl_lab](https://www.instagram.com/dctl_lab/)）が Instagram Reels に自動投稿するための、動画の置き場です。

Instagram の Content Publishing API は動画を**公開URLから取りに来る**仕様で、
ローカルファイルの直接アップロードは（Instagram ログインの経路では）できません。
そのためだけに置いています。

- 中身は DaVinci Resolve 用 DCTL の紹介ショート動画（縦 1080×1920・20〜35秒）
- 同じ動画は [YouTube](https://www.youtube.com/@DCTLLab) と Instagram でも公開しています
- 製品は [BOOTH](https://dctl.booth.pm)（日本語・円）と [English store](https://dctl-lab.lemonsqueezy.com)（USD）

コードは入っていません。
